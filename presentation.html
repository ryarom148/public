What is LangGraph?

Stateful Graphs

Model complex loops and conditional logic as a state machine.

Persistence

Built-in checkpointing allows agents to resume after failure or human-in-the-loop steps.

Streaming

Real-time updates of token output and internal state changes.

Cycles

Unlike standard chains, graphs support multi-step reasoning loops.

What is Deep Agents?

The "Opinionated Harness" for LangGraph

  • Built-in Planning: High-level task decomposition using write_todos.
  • Sub-agent Delegation: Offload complex sub-tasks to isolated agents to save context window.
  • Virtual Filesystem: Pluggable memory storage for long-term data and large context management.
  • Human-in-the-Loop: Native hooks for manual oversight and decision steering.

How to Use

from deepagents import create_deep_agent

# 1. Define a specialized sub-agent
coder = {
    "name": "developer",
    "description": "Writes and debugs Python code.",
    "tools": [python_repl_tool],
}

# 2. Initialize the Harness
agent = create_deep_agent(
    model="gpt-4o",
    subagents=[coder],
    memory="local_fs"
)

# 3. Execute with planning
agent.invoke({"messages": [{"role": "user", "content": "Build a CSV parser"}]})
